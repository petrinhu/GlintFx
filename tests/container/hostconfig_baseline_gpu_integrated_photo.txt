# Measured baseline for check_isolation.sh's variant "gpu_integrated_photo" (QA-COMPOSED-PATH G2-fix1, D-W8-F18).
# It is the HostConfig of the container tests/container/composed_photo.sh photographs: the INTEGRATED GPU node,
# a ceiling of 512 processes, and nothing else. Same discipline as hostconfig_baseline_gpu_integrated.txt (G1b):
# a live capture, not hand-written. Measured with Docker 29.8.2.
#
# Capture (14/10/2026, Docker Server 29.8.2, image fedora:44; a HostConfig does not carry image content, and
# the same run measured the gpu_integrated recipe equal to hostconfig_baseline_gpu_integrated.txt):
#
#   docker create --name glintfx-g2fix1-cap-foto --cap-drop=ALL --cap-add=SYS_NICE --pids-limit 512 \
#       --device /dev/dri/renderD128 -e KWIN_SCREENSHOT_NO_PERMISSION_CHECKS=1 \
#       -e KWIN_WAYLAND_NO_PERMISSION_CHECKS=1 fedora:44
#   docker inspect --format '{{json .HostConfig}}' glintfx-g2fix1-cap-foto
#   docker rm glintfx-g2fix1-cap-foto
#
# The container was NEVER started: docker create only builds the HostConfig, so no GPU was opened (GODS_LAWS.md
# L-09). renderD128 is the Intel integrated node (vendor 0x8086); the GeForce (renderD129) is not in this file.
#
# The only difference from hostconfig_baseline_gpu_integrated.txt is "PidsLimit": null there, 512 here (checked
# field by field by the capture). The two KWin variables live in .Config.Env, which is not the HostConfig; the
# photo driver checks them itself (the container's environment is the image's plus exactly those two).
#
# Placeholders: the same three as hostconfig_baseline_gpu_integrated.txt (ConsoleSize, the thermal_throttle entries
# of MaskedPaths, OomKillDisable), applied with the same sed steps normalize_host_config() runs.
#
